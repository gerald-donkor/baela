# Official Claude Code assets

Downloaded on 2026-10-08 from Anthropic's official press kit:

- Press kit: https://anthropic.com/press-kit
- Official product reference: https://claude.com/product/claude-code
- Official documentation: https://code.claude.com/docs/en/overview

The supplied `Claude Code logo - Slate.svg`, `Claude Code logo - Ivory.svg`, and `Claude Spark - Clay.svg` are saved locally as `claude-code-slate.svg`, `claude-code-ivory.svg`, and `claude-spark-clay.svg`. PNGs are rasterized derivatives for Canvas playback; geometry, proportions, and colors are preserved.

The official SVG fills provide clay `#D97757`, slate `#151514`, and ivory `#FAF9F5`. Supporting shell gray, mineral, and peach were taken from Claude's product-page CSS during the design research.

These marks remain Anthropic's property. Their appearance identifies the subject of an independent Baela tutorial; it does not indicate Anthropic endorsement or sponsorship. Logos are not recolored, distorted, rotated, or redrawn.
