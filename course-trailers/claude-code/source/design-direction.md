# Claude Code Tutorial — creative direction

A 28-second editorial motion film that turns one question into an understandable code change. The terminal is the subject, not a decorative side panel. A macro prompt becomes a project session, then a connected file/code workspace, then a focused diff. Resolve into the untouched official Claude Code lockup and a large “Tutorial” title.

## Tokens
- Official slate wordmark: #151514; warm ivory: #FAF9F5; clay: #D97757 (press-kit SVG fills).
- Shell gray: #262624; mineral: #629987; peach: #EBC9B7 (official Claude product CSS tokens).
- Type: Source Serif 4 Display for instructional headings and “Tutorial”; Geist for supporting language; Geist Mono for commands and code. The official wordmark is a bundled SVG, never typeset.
- Composition: 120 px safe margins; dominant, readable work surface; no more than four short code lines per reading beat. The workspace itself moves and responds.
- Motion: deliberate camera pullback, shared-position cuts, precise typing, file-selection focus, diff line reveal. No logo rotation, morphing, recoloring, or non-uniform scaling.

## Sequence
0–4.6: official lockup, a large question typed into a borderless terminal.
4.6–9.0: pull back to project shell; `cd my-project`, then `claude`.
9.0–14.0: reveal a compact project map; ask how a page works and highlight the relevant file.
14.0–18.2: describe a small label change; inspect a concise before/after diff.
18.2–21.0: the workspace resolves into three learning verbs, reinforcing the practical loop.
21.0–28.0: official wordmark + Tutorial, course call to action and independently branded Baela close.

## Critique against rejected version
The previous film repeated oversized headings next to terminal cards. This version makes the terminal full-frame, uses editorial scale changes, connects each action to the next shot, and reserves the title treatment for the close. Ivory/clay/slate are intentional official brand colors for this subject. Sparse supporting copy leaves enough time to read the examples at playback speed.
